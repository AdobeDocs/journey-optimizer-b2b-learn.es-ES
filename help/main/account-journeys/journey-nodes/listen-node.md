# Escucha de un nodo de evento

Use el nodo [!UICONTROL Listen for an event] de [!DNL Adobe Journey Optimizer B2B Edition] para avanzar un recorrido cuando se produzca un evento. Compare eventos de cuenta y persona, defina criterios coincidentes y configure tiempos de espera para controlar cuánto tiempo espera el recorrido.

>[!VIDEO](https://video.tv.adobe.com/v/3443219/?quality=12&learn=on)

## Esenciales del nodo de escucha

El vídeo abarca estos temas:

* La diferencia entre los eventos de cuenta y los eventos de persona.
* Criterios coincidentes para los déclencheur de evento.
* Configuración del tiempo de espera para eventos que no se producen en el tiempo especificado.

## Documentación relacionada

Para ver los eventos admitidos, los pasos de configuración y las opciones de tiempo de espera, consulte [Escuchar un evento en la guía del usuario](https://experienceleague.adobe.com/en/docs/journey-optimizer-b2b/user/journeys/journey-nodes/listen-for-event-nodes){target="_blank"}.
