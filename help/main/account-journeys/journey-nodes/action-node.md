# Realizar un nodo de acción

Use nodos de acción en [!DNL Adobe Journey Optimizer B2B Edition] para definir acciones para cuentas o personas en un recorrido. Compare acciones de cuenta y acciones de personas, y aprenda qué acciones admite cada tipo de recorrido.

>[!VIDEO](https://video.tv.adobe.com/v/3443248/?captions=spa&quality=12&learn=on)

## Aspectos básicos del nodo de acción

El vídeo abarca estos temas:

* El propósito de los nodos de acción en un recorrido.
* La diferencia entre las acciones de cuenta y las acciones de personas.
* Compatibilidad con acciones en todos los tipos de recorrido.

## Documentación relacionada

Para ver los pasos de configuración y las acciones de personas y cuentas admitidas, consulte [Realizar una acción en la guía del usuario](https://experienceleague.adobe.com/es/docs/journey-optimizer-b2b/user/journeys/journey-nodes/action-nodes){target="_blank"}.
