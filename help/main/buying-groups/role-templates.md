# Plantillas de función del grupo de compras

Obtenga información sobre cómo generar plantillas de funciones en [!DNL Adobe Journey Optimizer B2B Edition]. Estas plantillas definen quién participa en una decisión de compra, cómo se asignan las personas a los roles y qué hace que un grupo de compra sea completo. Este vídeo explica la creación de plantillas, la configuración de funciones y la publicación.

Este tutorial es para especialistas en marketing y administradores que utilizan [!DNL Journey Optimizer B2B Edition] para el marketing basado en cuentas y desean dirigirse a las partes interesadas adecuadas en cada cuenta.

>[!VIDEO](https://video.tv.adobe.com/v/3453303/?captions=spa&learn=on)

Descubra cómo:

* Abra el inventario de plantillas de roles en Grupos de compra y distinga las plantillas de borrador de las activas.
* Cree una nueva plantilla de rol con un nombre y una descripción únicos.
* Configure una función, incluida su ponderación, asignación automática y requisito de integridad.
* Defina las condiciones de asignación para cada rol, como la coincidencia en el puesto.
* Para incluir a todos los participantes, agregue más funciones, como Toma de decisiones, Profesional e Influenciador.
* Establezca la prioridad de funciones para que las personas se asignen a la primera función cuyas condiciones cumplan.
* Utilice la configuración Puntuación de integridad para establecer el número de miembros necesarios para cada rol.
* Publique una plantilla para que su estado cambie a Activo y esté disponible para los intereses de la solución.

Para obtener más información, consulte [Comprar plantillas de rol de grupo](https://experienceleague.adobe.com/es/docs/journey-optimizer-b2b/user/accounts/buying-groups/buying-groups-role-templates) en la guía del usuario.
